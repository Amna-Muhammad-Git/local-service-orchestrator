# Amigo mobile app — Phase 4

Amigo is a simple Expo/React Native prototype for the Smart Local Service
Orchestrator. This phase focuses on the mobile experience and uses mock data.
Backend networking will be connected in Phase 5.

## Run

From this directory:

```sh
npm install
npm start
```

Then press `w` for web, or scan the Expo QR code with Expo Go.

## Phase 4 flow

Welcome → Login/Register → Home → Provider results → Booking confirmation → My bookings

The Help button opens a short in-app guide explaining how Amigo works. The
colors are based on the root `theme.png` reference:

- Cotton Rose: `#E5C1BD`
- Bone: `#D2D0BA`
- Dry Sage: `#B6BE9C`
- Muted Teal: `#7B9E87`
- Blue Slate: `#5E747F`
